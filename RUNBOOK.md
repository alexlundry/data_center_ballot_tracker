## Election day
- 6:00 pm ET: start `Rscript R/watch.R 120` on the Mac (push access, drop folder synced). It is the main loop, not a fallback: only it reads the drop folder (16 Ohio sources) and Clarity (Illinois's six and Downe NJ), and GitHub ran the 5-minute cron just twice between midnight and 1:30 pm ET on Nov 3. The `Update results` workflow stays on as a backup for the other feeds and the sheet; `gh workflow run update-results.yml` starts one by hand.
- 7:00 pm ET: Volusia County (Edgewater) opens. 7:30 pm: all 21 Ohio measures. 8:00 pm: Maine (8), Illinois (7), Kansas (3), Downe Township and Belvidere NJ, Harwood ND. 9:00 pm: Rock County WI. 10:00 pm: Clark County NV. 11:00 pm: LA County CA.
- Wall screen: https://datacentersontheballot.com/?tv (Escape or Exit TV mode to leave). To point someone at one race, open it and use Copy link (`?race=<race_id>`).
- As each county's first numbers post, open its page and compare to the dashboard row. If the row still says "Not yet":
  1. Look at the Action log (or `watch.R` output) for that `race_id`. "no contest matched" means the `contest_pattern` regex is wrong: copy the exact contest name from the page into `sources.csv`. "could not map choices" means the choice labels are not Yes/No: set `yes_pattern` / `no_pattern`.
  2. If the page is a PDF, switch `adapter` to `pdf` and put the PDF URL in `api_url`.
  3. If nothing works within a few minutes, key the numbers into the Google Sheet with `override = TRUE`. Manual beats automated. Keep updating that row as the county updates.
- **Ohio drop folder (16 sources on `boe.ohio.gov`, `huron.boe.ohio.gov`, `liveresults.boe.ohio.gov` and Franklin's ENR).** These hosts block every script, so the pipeline never requests them. Instead:
  1. Run `make drop`. It lists each county page to open and which races have no file yet.
  2. Open the page in your normal browser and save the **cumulative or summary** results into the drop folder (`$DCBT_DROP_DIR`, the synced Election Night Drop folder; `~/Downloads/dcbt_drop` if unset). Save PDFs as they come; save ENR pages (Butler, Lucas, Franklin) with File > Save Page As > "Webpage, Complete". Any filename works: the pipeline matches files to races by the contest text inside them and reads the newest match. Files named with "precinct" or "detail" are ignored.
  3. Repeat whenever a county posts an update. The loop picks it up on its next pass, and the result's `as_of` is the file's download time, not the fetch time.
  - Only files modified on or after Nov 3 are read (`DCBT_DROP_SINCE` overrides). GitHub Actions has no drop folder, so these 16 sources only update from the Mac loop. Ashville is no longer one of them: Pickaway moved to Enhanced Voting, which the pipeline reads directly.
  - Butler (24) and Lucas (23) ids are filled in; Franklin's is still `ELECTION_ID` (replace it so the source link works).
  - The ENR folders (`liveresults.boe.ohio.gov/ENR/butlerohenr/` and the like) answer "Forbidden" on their own; open the election's page, `…/<id>/en/Index_<id>.html`, from the county board's results link. Nov 3 ids, seen in a browser that morning: Butler 24 (ISSUE 17 CITY OF TRENTON), Lucas 23 (25. Oregon Prohibition of Construction of a Data Center). Save the page with File > Save Page As > "Webpage, Complete" once the contest list has loaded; the `ohio_enr` reader was checked on both counties' May pages (Lucas's saved page is about 36 MB because it carries every precinct; that is fine). For Grove City a saved Franklin summary PDF also works. Franklin: follow https://vote.franklincountyohio.gov/election-info/2026.
  - Formats checked against May 5, 2026 files (fixtures in `R/tests/testthat/fixtures/`): Ashtabula, Defiance, Licking and Wyandot (Electionware; Pickaway's May file too, though it moved to Enhanced Voting for Nov 3) and Champaign and Clinton (Hart) are text PDFs the reader handles. **Huron posts a scanned image** even on election night (its May unofficial canvass, timestamped 9:32 pm), so Monroeville needs manual entry in the sheet. Adams's May file online is a scanned official canvass; whether its election-night PDF is text is unknown, so be ready to enter Sprigg and Monroe by hand.
- Mark a race `status = final` in the sheet once the county shows 100% precincts or "final unofficial". For Alhambra CA and Boulder City NV, wait until the county says its count is final: there "all precincts in" still leaves mail ballots, and the dashboard keeps them under Still out until `final`.
- **Still out notes.** The dashboard's Still out list shows every measure without a complete count, with a line on when to expect more (`results_expected` in `data/races.csv`). When you learn something better (a clerk says the count resumes at 1 pm, a town will post Thursday), type one plain sentence into `public_note`, column Z of the sheet's `manual_results` tab. It is public, it shows even with no vote counts, and it replaces the registry line for that race. Clear it once the count is complete. Staff-only notes stay in `update_note` (column X).
- Use the **Copy summary** button for a plain-text update to paste into email or Slack. It ends with the races that have no results posted and when to expect them.

- "Votes remaining" assumes equal-size precincts. Say "estimate" if you quote it.
