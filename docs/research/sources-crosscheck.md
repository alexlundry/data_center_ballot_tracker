# Cross-check against the Ohio SOS Local Questions and Issues file (Oct 16, 2026)

File: `docs/source-docs/ohio-sos-2026-11-general-qandi.xlsx` (Issues Summary sheet, 1,973 rows; last saved Sept 18, 2026; 242 Miscellaneous questions). It lists county, subdivision, question type and a one-line Purpose, with no issue numbers and no ballot text.

Confirmed: Sprigg and Monroe townships (Zoning amendment), Trenton (IX 9.06), Urbana (listed as Article VII, Section 8.07), Wilmington O-26-04/05/06/07, Defiance (1.12), Grove City (XI), Monroeville ("Shall the proposed ordinance allowing data center development be adopted?", so a binding proposed ordinance rather than an advisory question), Perry Village ("Shall the ordinance amending Chapter 133.01 ... be adopted?"), Pataskala (XI 11.09), Granville (X 10.12), Oregon (XIII 8), Ashville (same question wording), Hubbard (same question wording), Sunbury (misspelled "Sunsbury", XI), Upper Sandusky (Article XVII, Section 17.13, previously unconfirmed).

The Ashtabula BOE approved the Issue 10 charter amendment Aug 26 pending SOS review, and News 5 Cleveland and the Star Beacon report it on the ballot; kept, flagged for verification against the county sample ballot.

In the file but not a data center measure (checked by search): Brown Township, Franklin County (Issue 40, general zoning plan); Perry Township, Licking County (zoning plan adoption); Darby Township, Madison County (zoning resolution); Paris Township, Portage County (Issue 31, zoning code repeal; opponents mention data centers but the petition is a general repeal); Franklin Township, Morrow County (zoning amendment, no reporting found).
